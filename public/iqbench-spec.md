# 模型智商测评台 · 题库与评分标准（bench v7）

版本：bench v7（规格补丁 7.1）  
实现：网页默认每单元 1 次；正式 ×3 未默认开启。Q16 几何在浏览器里按真实渲染坐标测量（getBBox/getCTM，SMIL 定格 t=0）；无渲染环境时回退静态结构判分并标「几何未测」。

**v7 变更**：Q7 由参数化糖果题换成袜子配对，压缩同构题家族占比；Q12、Q13 参数化防背题；数字题按数值等价匹配（0.10 = 0.1）；Q16/Q17 用不带「最终答案行」要求的专用系统提示。权重：主信号（最坏保证 / 抗记忆）2.5；作图 1.0、格式 0.6。速度 1.5× 时限内不扣卷面，3× 才降到 0.88。

**v7.1 补丁（实现，题面数字未改）**：

- 抽取认 Markdown 包装（加粗、标题、代码块）以及英文 `the answer is` / `final answer`。
- 正文为空且 `finish=stop` 时，用思维链判分（Q17 除外）。糖果题额外扫思考末尾 2000 字，避免槽抽空把 25 打成 0。
- 流式空窗按题：预算 ≥90s（Q4/Q6/Q7/Q8）思考 300s / 正文后 90s / 硬顶 12min；Q16 思考 240s / 180s / 15min，未闭合 SVG 续写而不是压缩重开；其余思考 180s / 正文后 50s。
- `finish=stop` 正文 0 字 = 模型把答案写在 reasoning 里就停了，**不是时间不够**。`idle` 才是空闲掐断，`length` 才是写满上限。

## v7 评分体系

| # | 规则 |
|---|---|
| 1 | IQ = `round(100 + 90 × (加权通过率 − 0.5))`，量程 55–145，100 = 对一半 |
| 2 | 榜单带 95% 置信区间（对计分单元 bootstrap）；差 <20 或区间重叠视为同档 |
| 3 | 参数化题每次会话换实例；标准答案由求解器算出 |
| 4 | 压缩提示后仍无产出记 fail（超预算无产出），不剔除分母 |
| 5 | 速度系数只进卷面分，不进 IQ |
| 6 | 同时报等权通过率，作权重敏感性检查 |

### 作答与抽取

系统提示：禁止工具；最后单独一行 `最终答案: <短结论>`。允许 Markdown。Q16/Q17 例外：专用系统提示只要 HTML / JSON。

抽取顺序：

1. 去 Markdown / HTML 标记  
2. 正文非空 → 用正文；正文为空（含 `finish=stop` 只写了思维链）→ 用思维链（Q17 不用思维链）  
3. 最后一条答案槽：`最终答案` / `最后答案` / `本题答案` / `答案:` / `final answer` / `the answer is`  
4. 中文数字映射；否定守卫（「不是丙」不算「丙」）  
5. 数字按数值等价（0.10 = 0.1；217 不算 21）  
6. Q6/Q8 若槽未命中标准/半分答案，再扫文本末尾 2000 字  

### 流式等待（不进 IQ）

| 题 | 思考空窗 | 正文后空闲 | 硬顶 |
|---|---:|---:|---:|
| Q4 / Q6 / Q7 / Q8（预算 ≥90s） | 300s | 90s | 12min |
| Q16 | 240s（SVG 未闭合也按此档） | 180s | 15min；未闭合则续写 |
| 其余 | 180s | 50s | 10min |

Q16 半截图接续写，不再走「压缩重开」。其它题正文空或被截才压缩重试。

### 通过与半分

- `ok` 仅当正确性分达到单元满分（Q16a ≥7/10；无渲染环境回退时 ≥6/8）
- 半分有卷面、不进 IQ：Q6=29、Q7 公式值、Q8=25；Q4 只有遗传链给 7 分；Q5 只答下降给 5 分

## Q1 安眠药（crt，6 分，55s）

病人已睡，医嘱睡前口服安眠药，药未发。护士怎么做？

**答案**：不叫醒、不喂药（暂缓给药并记录亦可）。

**判分**：命中「不叫醒 / 不喂 / 不必吃药 / 无需服药 / 不给药 / 暂缓给药 / 暂不给药 / 持药观察 / 已经睡着就不用」，且无强制叫醒。

## Q2 洗车（crt，5 分，45s）

车在楼下，洗车店 4 公里。如何前往？

**答案**：开车去（开车/驾车/驾驶/自驾均可）。走路/打车/骑车零分。

## Q3 球拍与球 · 经典（crt，6 分，45s）

一共 1.10 元，球拍比球贵 1 元。球多少钱？

**答案**：0.05 元。作为 Q9 污染对照锚。

## Q4 红绿色盲（science，14 分，90s）

改 38→88，父亲说 8 一半绿一半红，随后崩溃。

**答案**：女儿色盲 + 父非色盲 + 伴 X 隐性 → 非亲生。

**判分**：遗传+亲子 14 分通过；仅遗传链 7 分不通过。

---

## Q5 船锚水位（science，10 分，60s）

船上铁锚扔进池底，水位升/降/不变？

**答案**：下降（重量排水 > 体积排水）。

**判分**：下降且有排水/浮力/体积/密度理由 → 10；只答下降 → 5。

---

## Q6 经典糖果题（worstcase，16 分，120s）

圆 7/9/8，星 7/6/4。保证（圆苹∧星桃）∨（圆桃∧星苹）。最少总数？

**答案**：21 = 9 圆 + 12 星。29 为盲取（7+9+8+4+1），8 分不通过，标「替代建模」。

---

## Q7 袜子配对 · 参数化（worstcase，16 分，120s）

抽屉里 3–4 种颜色袜子，各色 2–7 只，黑暗中摸取，保证凑出 p 双同色（p∈2–4）。求解器按库存穷举最坏情况。

只出「库存约束生效」的实例：真实答案 ≠ 无限库存公式 `2p + c − 1`。命中真实答案满分；答成公式值半分，标「替代建模」。

---

## Q8 糖果题变体（antimemo，16 分，120s）

圆：苹果 5、桃子 8、西瓜 6；星：苹果 4、桃子 3、西瓜 5。规则同 Q6：**事先**定圆形拿几个、星形拿几个（只辨形状），最坏仍保证（圆苹∧星桃）∨（圆桃∧星苹）。

**满分 17** = 圆 7 + 星 10。推导：堵住四类对手（圆全西瓜 → 圆≥7；星全西瓜 → 星≥6；两边无苹果 → 圆≥15 或 星≥9；两边无桃子 → 圆≥12 或 星≥10）。最小即 7+10。

**25 半分**（盲取）：一直摸到无法再回避，19+5+1。标「替代建模」，不进 IQ。  
**21** 记「疑似套用经典答案」（本表下 21 也是合法非最优可保证数）。

正文 0、思维链写 `the answer is 25` 仍按 25 半分，不因没写「最终答案:」打成 0。

## Q16 鹈鹕骑车（draw 10 + format 4，150s）

内联 SVG，禁止 img/canvas/base64/外部图。id：pelican-body/beak/pouch、wheel-front/rear、chain、pedal-left/right、foot-left/right。viewBox 恰为 `0 0 400 300`。chain 必须可见，空组不算。

流被掐且 `<svg>` 未闭合时 **续写接上**，不压缩重开。思维链里的 SVG 可拿去判分。已闭合的 SVG 即使 `finish=error` 也不当截断扔掉。

**Q16a（≥7 通过；仅无渲染环境回退时 ≥6/8 并标「几何未测」）**

判分把 SVG 挂进隐藏容器，按真实渲染坐标测量（任意 transform 均生效，SMIL 定格 t=0）：

- 双轮 rotate 2：动画在轮子自身/后代、href 指向该轮、或只包住该轮的父组上均可；单轮 1。
- 踩踏动画 2：脚或脚踏自身/后代、href 指向、或不含车轮的曲柄父组带动画；文档有动画但未绑定 1。
- 脚贴脚踏 2：脚心距对应脚踏心 < 渲染轮半径 40%；单脚 1。
- 画面内 2：只测鹈鹕/车轮/脚是否在 viewBox 内（太阳等装饰出框不扣）。关键件中心飞出记「乱飞」得 0 且再扣 2。全部 ≥92% 得 2，≥75% 得 1。
- 鹈鹕形态 2：长扁喙（宽 ≥ 1.4×高）+ 喉囊在喙下方且相邻 + 身体面积 ≥ 1.5×喙面积；三项全中 2，中两项 1。

**Q16b（满分才通过）**

10 个 id 2；viewBox 1；完整 HTML 1。

位图/canvas → a、b 全 0。整题展示的通过状态 = Q16a 与 Q16b 都通过。

## 渠道鉴定（不计分，可开关）

主测评结束后逐模型追加 15 个探针问题，结果只打标签，不进 IQ、不进卷面：

- **知识阶梯（13 问）**：按时间排列的客观事件（2023Q4 → 2026Q3，含 2025/2024 诺贝尔奖、超级碗 LX、2026 世界杯决赛、GPT-5.6/Claude Fable 5 发布等）。取答对的最晚季度作为「知识≈XXXXQX」估计；答「不知道」记 `?` 不算错。判定只看「最终答案行」，关键词正则任一命中即对。
- **联网嫌疑**：若答对了距测评日 45 天以内的事件（阶梯顶格条目刻意选很新的事件），标记「疑似联网」——模型训练数据不可能覆盖，多半是网关注入了搜索。
- **juice 探针（1 问）**：询问上下文中是否存在名为 juice 的数值参数。报出具体数字 → 标「疑似 Codex 反代」（juice 是 Codex CLI 注入的推理努力参数，正经 API 渠道不会有）。
- **身份自报（1 问）**：记录模型自称的名称与版本，仅供与所选模型名对照，自报不可信、不做自动判定。

- **降智对照**：跑分结束后拉取全网同名模型的公开分数分布（中位数 / 下四分位）。样本 ≥5 次、本次 IQ 低于全网中位 12 分以上、且不高于下四分位时，标「疑似降智渠道」。对照在本次成绩上传之前拉取，不会掺入自身。

探针使用专用系统提示（要求凭记忆作答、不知道就答不知道）。事件表在 `src/lib/probes.ts`，会随时间过期（最新条目距今超 90 天时界面会提醒），补新条目保持 `happenedAt`/`accept` 格式即可。

鉴定标签会进榜单：模型榜（本机与公开）显示见过的最新知识季度；渠道榜按主机聚合 ⚠ 联网 / juice / 降智标记，任一场次中招即标。
